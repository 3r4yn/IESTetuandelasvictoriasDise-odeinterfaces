Lo que aprendes lo puedes crear.

En la Formación Profesional, la teoría cobra sentido cuando se transforma en proyectos reales. Aquí verás los módulos esenciales que he cursado y cómo cada uno aporta las herramientas necesarias para maquetar, programar y construir aplicaciones web completas.

Mi mapa de aprendizaje

6 módulos · 6 proyectos de ejemplo

Seis módulos para conectar los conocimientos con proyectos prácticos y visualizar un futuro en el desarrollo web.

[] 01

Lenguajes de marcas

HTML · CSS · XML

Qué aprendería: crear la estructura web semántica y aplicar hojas de estilo CSS para maquetar páginas web funcionales.

Para mi futuro profesional: construir la base técnica para el desarrollo y diseño de sitios web bien estructurados.

☁️ 02

Bases de datos

SQL · Modelado relacional

Qué aprendería: modelar bases de datos relacionales, realizar consultas complejas con SQL y garantizar la integridad de los datos.

Para mi futuro profesional: gestionar información de forma eficiente y segura para integrarla con aplicaciones web.

{ } 03

Desarrollo web en entorno cliente

JavaScript · DOM · Fetch

Qué aprendería: crear interfaces interactivas, gestionar eventos en el navegador, manipular el DOM, validar formularios y consumir APIs REST de forma asíncrona.

Para mi futuro profesional: desarrollar la capa front-end dinámica de las aplicaciones web y construir interfaces fluidas e interactivas para el usuario.

⚙️ 04

Desarrollo web en entorno servidor

PHP · HTTP · API REST

Qué aprendería: procesar solicitudes del cliente, gestionar sesiones de usuario, aplicar mecanismos de autenticación y conectar la lógica del servidor con bases de datos relacionales.

Para mi futuro profesional: construir la arquitectura back-end de los proyectos web y garantizar la seguridad y persistencia de los datos.

▦ 05

Diseño de interfaces web

Figma · CSS · Accesibilidad

Qué aprendería: diseñar prototipos interactivos en Figma, organizar contenidos utilizando Flexbox y CSS Grid, y aplicar principios de jerarquía visual, usabilidad y accesibilidad.

Para mi futuro profesional: diseñar experiencias de usuario (UX/UI) atractivas y convertir prototipos visuales en código web maquetado de forma limpia y accesible.

☁↑ 06

Despliegue de aplicaciones web

Git · Linux · Servidores web

Qué aprendería: gestionar repositorios con Git, configurar servidores web (Apache/Nginx), instalar certificados de seguridad HTTPS y automatizar la publicación de proyectos web.

Para mi futuro profesional: administrar el entorno de producción, desplegar proyectos en la nube y garantizar la disponibilidad y rendimiento del sitio web.
